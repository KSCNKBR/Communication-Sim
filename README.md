# Communication-Sim

> 通信系统仿真与学习笔记
> 
> 记录信号处理、调制解调、信道建模等方面的 MATLAB/Python 仿真项目

## 📌 关于本仓库

这个仓库用于整理我在通信与信号处理方向的**课程设计、自主仿真实验和文献阅读笔记**。

主要涉及：
- 数字调制技术（QPSK、QAM、OFDM）
- 多天线系统（MIMO）
- 信道编解码
- 无线信道建模

## 📁 目录结构

```
Communication-Sim/
├── QPSK_Simulation/        # QPSK 调制解调链路仿真
├── OFDM_Simulation/        # OFDM 系统仿真（待完善）
├── MIMO_Simulation/        # MIMO 信道与检测算法（待完善）

```
