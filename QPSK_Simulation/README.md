## 系统架构

## 关键参数
- 码元速率：10 kHz
- 采样频率：400 kHz
- 载波频率：100 kHz
- 滚降系数(R)：0.5
- 滤波器跨度：20 个码元
- 每码元采样点数：40

## 技术要点
- 使用 `rcosdesign(R, span, Nsam, 'sqrt')` 设计根升余弦脉冲成型滤波器
- 上变频采用正交调制：`SigPassBand = I·cos(2πfct) - Q·sin(2πfct)`
- 接收端匹配滤波器与发送端成型滤波器一致，实现无码间干扰(ISI-free)传输
- 通过 `eyediagram` 验证接收信号的眼图张开度，评估系统性能
